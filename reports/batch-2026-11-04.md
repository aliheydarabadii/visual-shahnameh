## Process and proposed changes

These are proposals only. The shared files were left unchanged.

1. **`scripts/check_section.mjs`: fix the ffmpeg error path.** Set an adequate `maxBuffer`, or use `ebur128=framelog=verbose` at info log level so frame-by-frame messages are suppressed while the summary is retained. Inspect both `ff.error.code` and `ff.status`; reserve "ffmpeg not found" for `ENOENT`. A buffer overflow or failed encode should be a failure with its real cause. Write a valid full-length m4a after measurement.
2. **`scripts/check_section.mjs`: disable watch/HMR for deterministic checks and isolate failures per section.** A source save should not navigate a page during offline rendering. Catch render failures, save an explicit `result.json`, close that section's page, then continue to later ids. This would preserve batch results instead of crashing the whole command.
3. **`scripts/check_section.mjs`: paginate contact sheets below 16,384 pixels.** Keep every original frame, divide long sheets into numbered pages and include an explicit ending image. Assert the number and order of tiles, including the final beat. The 06.06 artifact demonstrates why a single tall sheet is insufficient.
4. **`docs/BUILDER_BRIEF.md`: put report creation before the first check.** Require a draft before checking, then fill the measured summary and finish time after a successful check. The current steps ask for a check to pass before a required report exists. Require stale phrases such as "Not run yet" and "in progress" to be replaced before completion.
5. **`AGENTS.md` and the brief: preflight availability and define failed-run handoff.** Check the requested Grok model and image-account availability before launch. Record task ids, image filenames already written, accepted/rejected files, check status and the exact remaining step. Credit exhaustion should leave a durable handoff; retries should require checking disk first. Cancel queued continuations before replacing a task so late images cannot duplicate completed work.
6. **`AGENTS.md` and the brief: establish section-range character variants before parallel painting.** Assign one owner per recurring figure and lock the age, robe, crown and weapon variant for each range, including the transition from 07.06 to 07.07. Include an approved reference painting with the prompt line. A fixed left-facing rule alone sometimes makes conversational staging awkward; define the allowed exceptions explicitly. Align AGENTS.md's new-character-files-only scope with STYLE.md's permission to append dated notes; builders appended age notes in this run.
7. **`scripts/next_sections.mjs`: improve contiguous load balancing.** The requested nine-agent script plan gave the last builder 386 couplets. The orchestrator regrouped the same ordered sections into 158, 223, 163, 202, 153, 148, 211, 165 and 221 couplets. Use a contiguous partition that considers the heavy tail before committing earlier bundle boundaries; keep zero-couplet headings with their adjacent story.
8. **`AGENTS.md` and the brief: document empty headings and claim renewal.** Permit a source heading with no couplets to use the minimal title treatment explicitly. Distinguish its expected warning from unfinished content. Claims expire after eight hours, shorter than this run's credit gap; prescribe renewal for active work and release for abandoned work.
9. **`docs/BUILDER_BRIEF.md`: make visual acceptance measurable.** Require one clear central light, a phone-safe main action, a reference comparison for every recurring character, and separate reports for exceptions. The current batch kept phone crops that lose the serpent or a combatant, several costume mismatches and competing lights. The report should make these visible to the orchestrator before conversion. Add a joint boundary review between builders whose sections share the same people.

10. **`scripts/check_section.mjs`: log stage timings.** Print the start and finish of text/art validation, screenshots, offline synthesis and ffmpeg separately, with audio duration and painting count. The final run spent long periods without console output after writing its sheets; stage timings would distinguish synthesis cost from screenshots, encoding and a stalled page.
