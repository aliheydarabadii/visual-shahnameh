# Character sheets

One file per recurring figure (kings, heroes, divs, famous horses), so the
same person looks the same in every chapter. `art/STYLE.md` rule 10 says how
to use them.

- File name: an ASCII slug of the usual English spelling (`rostam.md`,
  `rakhsh.md`, `zal.md`).
- Before painting someone, look here. If a sheet exists, paste its prompt
  line unchanged. If not, create it (copy any existing file as a template).
- Never rewrite another builder's prompt line; append a dated note instead.
